# 赛马游戏工作台

## 打开页面

在 AstrBot 管理面板中打开本插件的「赛马游戏」页面。找不到入口时，更新 AstrBot、重载插件并刷新页面。

## 编辑与保存

1. 在顶部选择事件包，或点击事件列表旁的「＋」新建事件。
2. 点击黄色积木填写名称、消息和作用目标；buff 使用下拉选择。
3. 拖入位移、buff、新增赛马等效果积木，接到事件内。随机、延迟等积木中需要放入子事件。
4. 点击「校验事件包」，通过后选择「保存到机器人」或「导出 JSON」。保存后自动重载，同名文件覆盖前会提示。

内置包可以作为副本编辑，保存为自定义包；只有自定义包能通过「删除事件包」删除，删除后保留备份。

日常编辑无需手写 JSON。灰色「高级字段」会保留旧数据，需要时再展开「高级 JSON」。重要草稿请及时导出备份，完整字段见 [事件详细模板](事件详细模板.txt)。

## AI 一句话生成

1. 在插件配置中开启「使用内置 AI，一句话生成事件」，保存、重载插件并刷新工作台。
2. 可选择「事件生成使用的模型」；留空使用 AstrBot 默认聊天模型，无需另填密钥。
3. 在右侧描述需求，收到结果后可继续对话修改。
4. 点击「导入编辑器」检查积木，或点击「导入并保存」直接保存到自定义事件包；覆盖前会提示。

AI 回复不会自动写入文件。刷新页面会清空对话，需要的结果请先导入或保存。

## 开发试跑

1. 打开「开发测试」，选择只测试当前事件或整个事件包。
2. 设置马匹、回合数等参数，点击「开始测试」。每行马匹填写为 `马名|初始位置`。
3. 用上一回合、下一回合或播放查看结果，也可以导出测试记录。

试跑使用独立场地，不影响群内比赛，也不会发送群消息。保持相同输入和随机种子，可以复现结果。
